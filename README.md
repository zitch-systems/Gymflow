# GymFlow — Gym Management Platform

Static multi-page app powered by Supabase.

## Deploy

Connected to Cloudflare Pages via GitHub. Push to `main` → auto-deploys.

## Stack
- HTML + vanilla JS + Tailwind CSS
- Supabase (PostgreSQL + Auth + RLS)
- Paystack (payments)
- Cloudflare Pages Functions (serverless API)
