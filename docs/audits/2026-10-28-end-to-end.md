# GymFlow audit — 28 October 2026

## Scope and outcome

Inspected public web navigation and forms, native member screens, shared membership/payment rules, WhatsApp configuration and receipt handling, production database health, scheduled jobs, and dependencies. This is not certification that every production journey works. Signed-in browser acceptance, real-device journeys and a successful live WhatsApp send remain unverified.

## Fixes

- Native membership screen: freeze requests, pending/frozen states, explicit auto-renew cancellation. Shared web/native date, ownership, gym and concurrency checks prevent false success and duplicate notices.
- Native renewal now supports explicit opt-in recurring billing through the same reservation, pricing and duplicate-mandate guard as web. One-time remains default. Changing the trainer price resets consent. Stale data cannot start checkout; callback text cannot by itself claim payment confirmation.
- Native documents/waiver and gym WhatsApp entry are accessible directly from Profile. Profile writes verify a saved row, hide internal DB errors and prevent duplicate taps.
- Web profile surfaces query failures instead of showing fabricated empty data.
- WhatsApp delivery receipts cannot regress read/delivered state; successful delivery clears stale errors; failed database writes surface as errors. Strict signature parsing and malformed-payload handling have regressions.
- Meta connector distinguishes omitted event-field data from an explicit empty list.
- Feature-page class reminder copy now describes the implemented morning email digest; waitlist promotion wording corrected.
- Next.js and matching ESLint config updated to 16.4.3. Meta SDK updated to 1.32.2 and Zod to 4.6.7, with bounded MCP validation. Expo CLI Zod patched with actual schema compatibility checks.
- Platform payment mapping failures now remain retryable instead of being mistaken for absent mappings. A failed current-subscription read cannot overwrite a mandate or cancel access. Successfully checked missing/conflicting ownership still requires operator repair.
